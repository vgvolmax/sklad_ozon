# Codex Cloud — среда проекта

## Active architecture

MVP является статическим browser application. Production assets коммитятся
напрямую, а пользователь открывает `app/index.html` через `file://`. В active
architecture нет шага установки зависимостей, сборки, сервера или runtime
bootstrap.

Codex обычно может работать с Agent Internet Access OFF. Стандартный Node может
использоваться разработчиком/CI для dependency-free команды `node --test`; он не
является пользовательским runtime requirement.

## Внешние ресурсы

Сеть нужна только тогда, когда конкретная будущая задача действительно требует
внешний ресурс, например добавления новой vendored browser library. Такое
требование должно следовать из scope задачи, а не быть постоянным preflight.

GitHub CLI может отсутствовать или быть не авторизован. Это не блокирует обычную
работу, если требования уже находятся в репозитории; публикация может выполняться
native возможностью Codex Cloud.

## Неизменное правило

**Environment limitations must not cause architecture drift.**

При реальном ограничении нужно сообщить точную команду и ошибку, сохранить
валидную проверенную работу и не добавлять сервер, package manager, build pipeline
или самодельную замену согласованному решению только ради обхода среды.
