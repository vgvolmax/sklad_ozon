# Отгрузки — отдельный интерактивный HTML

Откройте `sklad-ozon-shipments-demo.html` в браузере. Зависимостей и внешних запросов нет.
Демонстрационные данные; к Ozon макет не подключается. Production-файлы приложения не изменены.

1. Видны три готовых кластера. Казань и Екатеринбург остаются в плане.
2. «Исправить в плане»: для 39439 введите 5. Значение автоматически получает источник «Ручная».
3. Подтвердите 39439 и ручную кратность 51916. Оба кластера появятся в отгрузках.
4. Изменение кратности сбрасывает подтверждение. Количество не округляется.
5. Новый план сохраняет ручные значения, но требует повторного подтверждения.
6. В карточке задайте дату/время создания заявки либо «Без даты» (ручной запуск). Время — МСК; это не дата отгрузки.
7. Выберите кластеры и проверьте сводку. Подготовка имитируется; реальные заявки не создаются.
8. «Скачать настройки» выгружает JSON. В меню сценариев доступны скачивание HTML и сброс демо.

В макете localStorage имитирует справочник в папке приложения. В production потребуется серверное сохранение и состояние подтверждения для текущего плана.
Готовность означает готовность локального состава. Принимающий склад, доступность и окно отгрузки Ozon проверяет отдельно.
Каждая карточка соответствует отдельной заявке. СЦ, склад, SKU и количества — примеры.
Объём товаров — оценка без транспортной упаковки.

Автотест: `python prototype_checks/shipment_demo_browser.py`.
